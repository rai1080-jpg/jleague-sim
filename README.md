# Jリーグ順位予測（jleague-sim）

J1・J2・J3（2026/27 シーズン）の順位表・試合結果と、残り試合のシミュレーションによる
最終勝点・最終順位の予測を見るスマホ向け Web アプリ。

## 画面
- **順位表**：勝点・勝分敗・得失点・直近5試合、昇格/降格などのゾーン
- **最終予測**：予想最終勝点（80%の幅つき）、平均順位、優勝・ACL/昇格・PO・降格の確率、最終順位の確率ヒートマップ
- **日程・結果**：節ごとの結果と、未消化試合の勝敗予測
- **スタッツ**：チーム別スタッツ（得点・失点・シュート・被シュート・決定率・無失点・CK・反則・警告・退場・ホーム平均入場者、見出しで並べ替え）と得点ランキング
- **お気に入り**：チーム詳細の ☆ で登録（ブラウザに保存）。順位表の上に順位・予想・次の試合をまとめて表示し、各表で行を強調
- **分析**：優勝・昇格・残留の目安勝点、直近の注目カード、残り日程の厳しさ、チーム力ランキング
- スマホでは画面を左右にスワイプしてもタブを切り替えられる（指に追従し、勢いのまま流れて次のタブが減速しながら入る）
- チーム名をタップ：順位推移、最終順位の確率、目標までに必要な勝点、残り試合の勝敗予測

## 2つのデザイン
- `index.html` ＋ `style.css`：ライト版（淡い青灰の地）
- `night/`：ダーク版（黒い地にゆっくり動く抽象画の背景＝CSS の色のにじみ＋`night/bg-lines.svg`〈`tools/make_bg.py` で生成〉、半透明のすりガラス風カード、左サイドバー、大きな英字見出し）。ライト版からはダーク版へのリンクがあり、見ていたリーグとタブを引き継ぐ。`app.js`・`sim.js`・`config.js` と `data/` は共通で、
  `night/night.js` はダーク版だけのスクロール処理

## ホーム画面のアイコン
`icons/`（ライト版）と `night/icons/`（ダーク版）に PNG を置き、`manifest.webmanifest` と `apple-touch-icon` で指定している。
作り直すときは `python tools/make_icons.py`（Pillow が必要。確認用の一覧が `tools/icons-preview.png` にできる）。

## 予測の仕組み（sim.js）
1. 今季の得点・失点から各チームの攻撃力・守備力をポアソンモデルで推定（対戦相手の強さを考慮。
   試合数が少ないうちは `priorGames` 試合分だけリーグ平均に寄せる）。ホーム有利もデータから推定
2. 残り試合のスコアをポアソン分布で 10,000 回シミュレーション（チーム力の不確かさも毎回揺らす）
3. 勝点 → 得失点差 → 総得点 で順位を決め、確率を集計

設定は `config.js`（順位ゾーン、シミュレーション回数など）。

## ローカルで動かす
```bash
python fetch_data.py          # data/ に最新の試合データ・チーム別スタッツ・得点ランキングを取得
node tests/check.js           # 計算エンジンの確認
python -m http.server 8793    # http://localhost:8793 を開く
```

## 公開
GitHub Actions（`.github/workflows/update.yml`）が毎日 6:00 と、13:00〜23:30 JST は30分ごとにデータを取り直し、
GitHub Pages へデプロイする。定期実行では `compare_published.py` で公開中のデータと比べ、変化がなければ公開し直さない。データ（data/）はリポジトリに入れない。

データ出典：[J.League Data Site](https://data.j-league.or.jp/)
